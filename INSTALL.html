Install The Blueprint

The application is a local-first progressive web app. Upload the complete folder to an HTTPS static host, then add it to the phone's home screen.

Protect your data

Workout history is stored on the device. Use More → Backup and exports → Download JSON backup regularly, especially before changing phones or clearing browser data.

iPhone or iPad

  1. Open the hosted index.html page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Open The Blueprint from the new icon. Complete one online load before relying on offline use.

Android

  1. Open the hosted page in Chrome.
  2. Open the browser menu.
  3. Choose Install app or Add to Home screen.
  4. Open The Blueprint from the new icon. Complete one online load before relying on offline use.

Desktop test

From the extracted application folder, run:

python -m http.server 8080

Then open http://localhost:8080.

Immediate standalone version

Blueprint_Workout_App_Standalone.html contains the application in one file for testing or desktop use. It does not provide home-screen PWA installation or service-worker caching.
